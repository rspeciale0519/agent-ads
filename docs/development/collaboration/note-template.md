# Task message

- Sender: Codex or Claude.
- Recipient: Codex, Claude, or Rob.
- Task: task ID from the joint action plan.
- UTC time: use the actual time.
- Type: assignment, question, finding, handoff, acknowledgment, decision, or completion.
- Reply to: prior note filename, or none.
- Relay request: yes or no. Use yes only for unchanged publication through the guide's relay procedure.

## Message

State the result, question, or requested action in plain language.

## Files and evidence

List exact changed files, relevant commands, observed results, and any unavailable check.

## Dependencies and next step

State what can proceed and what requires a response. Name the owner of each pending action.
